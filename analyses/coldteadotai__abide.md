## 1. 接口形态
- 每条规则 = 一个 noul（"this edit 是否违反 rule X"），**一次调用带多规则问题**；verdict 输出概率 + 规则出处行
- **Jev 只看规则 + diff，不看对话史**——"第 200 次编辑和第 1 次被同样检查"：无上下文漂移是特性不是限制
- 规则两相位：`edit`（每编辑后）与 `turn`（回合末对整 diff）——"这轮是否加戏"在第 1 次编辑后无答案，相位设计=问题有效性边界
- 规则按 `scope` glob 分层（API 路由和样式表不该吃同一问题）

## 2. 校准与阈值策略（重点）
- **三带裁决**：≥0.8 → 命令代理当场修；0.5–0.8 → **只给人看note、不进代理上下文**（防噪声驱动改码）；<0.5 静默——与 snifftest 三带同构但分流对象不同（snifftest 中带给"无判定"，abide 中带给"人复审队列"）
- **死规则检测制度化**：措辞差的规则"逢事打分 0.4 永不发火"；`abide calibrate` 拿你的 git 史 20 个真实 hunk 打分，**把这类规则自动关掉**；`abide tune` 让代理改写它们
- 召回统计法（headline）：回放 93 个真实会话（1,256 edits / 147 turns / 2 repos / $0.22），Jev flag 39 edits + 15 turns，**独立评审只确认了 10 和 11**——flag 数与确认数并排印在 banner 上，turn 级 11/15 站得住、edit 级 10/39 自曝拉低
- 漏检可审计：无 key/断网时编辑放行但**记入 `.abide/events.jsonl`**，`abide report` 统计"多少检查没发生"

## 3. 工程质量
- 全路径 `exit 0` + 硬 deadline："hook 绝不能弄坏你的会话"——失败模式设计成让路而非拦截
- key 查找序：env → `.env.local` → `.env` → `~/.abide/.env`；**永不作为 flag 传递、永不记录**；零数据保留请求随每调用发出
- 成本实测带日期与路径："Measured 2026-09-18, direct to TypeSafe"，且 `abide bench` 让用户在自己机器重测
- `report/check/audit/bench/calibrate` 全部 `--json`；audit 把存量代码按"刚写下时"判定（33 路由 12 秒 ~1 美分）
- 指令文件哈希进 session-start：改了 AGENTS.md → rubric 自动重编译（政策-检查同步，与 jev-pref `sync` 同题）

## 4. 可移植模式清单
1. **独立确认召回表（→我们的复测表制度）**：自评产物送"独立一判"（我们用逆序盲审充当），报告并排印"flag 数 / 确认数"两列——DoD-3 复测表格式增补此双列。验收：任何进报告的自动 flag 表必须有确认列或显式"未确认"标记
2. **rubric 溯源行号**：我们 gold 集每条维度加"出自规范文件哪一节"字段，错误判决第一归因是规则文本而非模型——配合 batch03-S3 confident-and-wrong 表，wrong 条目直接带修订指针
3. **死规则 calibrate**：定期用历史样本测每条题的"发火率"，长期 ~0.4 恒不触发的题自动禁用并提示重写（对 jev_eval 题集做体检）。验收：注入 1 条永不发火合成题，体检必须点名
4. **中带=人复审队列**：0.5–0.8 不进自动动作、单列"给人看"档——我们盲审 0.6 隔离线的同型上位设计，可直接扩成三带
5. **漏检事件账**：评测跑不动/超时的样本显式记 `missed` 并进分母报告，禁止静默缩样
6. **相位分离**：章节级问题（"这章加戏了吗"）与段级问题（"这句 AI 味"）分相位跑，不混一次调用
- **反模式①**：规则本身由代理从指令编译（rubric 自动重编译）——省事但规则文本质量无门禁；我们 gold 题面必须人写死（与 zhuyansen 冻结标签同理），自动重写只作提案
- **反模式②**："up to 100x cheaper" 类比无出处（营销句），我们引用只取有日期有路径的实测句

## 5. 与本地 Jev 评测链路映射
- `jev_eval.py --check`：题集体检（§4-3 发火率）加为子命令候选；DoD-2 验收=合成永不发火题必须被点名
- 盲审协议：三带分流（自动采信 / 人复审队列 / 丢弃）替换现"一致即采"二值线；quarantine 队列语义与 abide 中带完全对齐
- Ending 二级树/Score 锚定：维度题面加"出处行"字段（§4-2），FINAL 规范文档反向可核
- 记忆教训"平均置信度 0.82 vs 实际 0.70"：abide 的 edit 级 10/39 确认率是同款事故的**自曝式**呈现范本——我们的报告学这个格式，不学它的数字
